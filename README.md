# Bio21 — 生物工程 21 天交互学习网站

React 18 + TypeScript + Vite，无运行时 UI 框架依赖。面向入门学习者的课程与概念模拟工具。

## 功能

- 21 天分阶段课程、关键词搜索、阶段筛选、随堂单选测验
- 本地保存课程完成状态与测验记录，可重置
- 术语知识库
- 交互实验室：DNA 互补链、中心法则分步动画、PCR 理想扩增计算、PCR 三阶段交互演示、Sanger 链终止测序示意、发酵参数教学模型
- 响应式布局与 Netlify SPA 路由回退

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run verify:static
npm run typecheck
npm run build
npm run dev
```

## 部署到 Netlify

- Build command: `npm run build`
- Publish directory: `dist`
- 仓库根目录包含 `netlify.toml`，`public/_redirects` 用于 SPA 回退。

## 教学模型边界

本项目中的 DNA、PCR、Sanger 和发酵可视化均为概念示意。它们不代表真实实验数据、临床建议或可直接执行的实验方案。实验操作应遵循经验证的方案、试剂说明和实验室安全要求。

## v1.9：章节题库与错题复习

- 新增独立“章节题库”页面，整合 21 道课程基础题与 21 道进阶题，共 42 道单选练习。
